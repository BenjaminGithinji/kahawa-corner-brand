# kahawa-corner-brand-identity# Kahawa Corner Brand Identity

> A badge-style logo and color system for Kahawa Corner, a fictional neighborhood coffee shop in Nairobi. This is a concept project for my portfolio.

![Kahawa Corner badge](kahawa-corner-badge.png)

Kahawa Corner is a new coffee shop aimed at young professionals, students, and remote workers. It needed a look that feels warm, local, and modern, and that stands out from the big coffee chains.
